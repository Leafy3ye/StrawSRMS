# 智慧餐饮综合管理系统（代号Strawberry）

> 本项目原为“咖啡馆综合管理系统”，现进行商业化改造，升级为“智慧餐饮解决方案” —— **智慧餐饮综合管理系统**，支持多租户机制，实现每个用户账号仅能访问自己店铺的数据。

---

## 📦 项目背景

- 原系统版本命名至 `v0.0.1` 后停止维护；
- 从 2025 年 7 月 1 日起，全面重构系统结构，采用租户架构，实现数据隔离；
- 启动 GitHub 上的版本控制与开发管理。

---

## v0.0.1 更新日志（2025/07/01）

- 完善用户注册流程，新增 **验证码校验功能**
- 引入多租户模块，**账号间数据相互隔离**
- 重构部分基础模块，准备商业化部署
- 系统正式接入 Git 进行版本管理
